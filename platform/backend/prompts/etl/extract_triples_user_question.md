請分析以下「資安考題」文本並萃取三元組。

處理規則：
1. 先閱讀題幹、選項與 Correct Answer，將「題幹 + 正確答案」重建為一個或多個可成立的資安知識陳述句。
2. 只從重建後的正確陳述句萃取三元組。
3. 未被標為 Correct Answer 的選項屬於干擾選項；除非題幹明確說明其角色，否則不得把干擾選項視為正確事實入圖。
4. **否定式提問例外**：若題幹為否定式（如「何者『不是』／『非』／『不屬於』／『錯誤』／『不正確』／『最不適切』」），則 Correct Answer 標記的是被排除或錯誤的敘述，而**其餘未被選為答案的選項反而是成立的正確知識**；此時應改以那些「未被選為答案的選項」所隱含的資安關係為知識來源萃取三元組（本點為第 3 點之例外）。被排除／錯誤的答案本身若無法形成合法 Schema Edge 則放棄，不要硬湊。
5. 若題目為複選題，僅使用 Correct Answer 列出的所有正確選項作為知識來源。
6. 若考題資訊不足、語意不明，或無法符合 system prompt 的 type、relation 與 Schema Edges，請不要萃取該三元組。
